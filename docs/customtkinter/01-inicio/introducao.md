# Introdução

Esta é a documentação oficial do CustomTkinter. Aqui você encontra informações detalhadas sobre todos os widgets disponíveis e como funcionam temas e appearance mode.

## Suporte

- **Dúvidas**: Abra uma discussão no GitHub Discussions.
- **Bugs**: Abra uma issue no GitHub Issues com a mensagem de erro completa e um exemplo mínimo que reproduza o erro.
- **Sugestões**: Abra uma issue no GitHub Issues, informando-se antes se a solicitação já foi feita para evitar duplicatas.

## Instalação

```bash
pip install customtkinter
```

## Upgrade

```bash
pip install customtkinter --upgrade
```

## Desinstalação

```bash
pip uninstall customtkinter
```
